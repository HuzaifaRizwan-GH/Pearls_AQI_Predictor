# Pearls AQI Predictor

An end-to-end Air Quality Index (AQI) prediction system for Karachi.

## Project Goal

Predict the Air Quality Index (AQI) for the next 3 days using weather and pollutant data.

## Project Structure

- `.github/` - GitHub Actions automation
- `API/` - Prediction API
- `dashboard_UI/` - Streamlit dashboard
- `data/` - Raw and processed data
- `feature_pipeline/` - Data collection and feature engineering
- `models/` - Trained models
- `notebook/` - EDA and experiments
- `training_pipeline/` - Model training
- `venv/` - Local Python virtual environment
